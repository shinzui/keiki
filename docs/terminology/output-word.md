# output word

The ordered list of events emitted by one edge execution.

The list may be empty, contain one event, or contain several events in declaration order. Its expression list has a fixed shape per edge; conditional event counts are represented by separate guarded edges.

See [the supporting source or guide](../../docs/guide/multi-event-commands.md).
