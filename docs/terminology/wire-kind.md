# wire kind

The JSON discriminator identifying an event constructor on the wire.

A kind override can preserve Placed after a Haskell constructor is renamed to OrderPlaced. The default comes from the constructor name; pinning it separates persisted identity from source spelling.

See [the supporting source or guide](../../keiki-codec-json/README.md).
