# B-view

A vertex-indexed presentation of the register slots designated live at that control vertex.

A Confirmed view may expose email and confirmedAt while hiding an obsolete confirmation code. The view is an optional projection over the register file, not a second execution engine or a persistent read-model service.

See [the supporting source or guide](../../docs/guide/b-views.md).
