# hidden input

A command input required by an edge that cannot be recovered from its invertible output fields.

If quantity appears only inside quantity times price, the product cannot supply quantity to structural inversion. Including quantity directly in an event field can make it recoverable. Coverage is checked across an edge's output word.

See [the supporting source or guide](../../docs/guide/output-invertibility.md).
