# topology diagram

A rendering focused on graph connectivity rather than the complete behavior of each edge.

Use a topology diagram to inspect which vertices connect. The primary readable Mermaid rendering also exposes guards, assignments, and event constructors; ordinary literals can be visible, while opaque literals remain redacted.

See [the supporting source or guide](../../docs/guide/mermaid-rendering.md).
